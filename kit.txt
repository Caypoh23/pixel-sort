# Pixel Sort — тест рынка

Браузерная демо-версия игры, ролики для соцсетей и автоматика теста: публикации по расписанию и ежедневный отчёт.

- **Демо:** https://caypoh23.github.io/pixel-sort/ (GitHub Pages, папка `docs/`)
- **Свежий отчёт:** [reports/latest.md](reports/latest.md), обновляется каждое утро в 08:17 по Ташкенту
- **Календарь публикаций:** [content/schedule.json](content/schedule.json)

## Что где лежит

| Путь | Что это |
|---|---|
| `docs/` | Сайт: игра (`index.html`), настройки (`config.js`), ролики (`clips/`), иконки, превью для соцсетей, политика конфиденциальности |
| `content/schedule.json` | 14 дней публикаций: ролик и подписи для Instagram, YouTube, Threads и X |
| `content/posted.json` | Что уже поставлено в очередь Buffer (пишет бот) |
| `scripts/autopost.py` | Ставит ролик дня в очередь Buffer на все подключённые каналы |
| `scripts/report.py` | Забирает воронку из PostHog и пишет отчёт в `reports/` |
| `.github/workflows/` | Расписание: автопостинг каждые 6 часов, отчёт каждое утро |
| `tools/engine/` | Исходники игры, генератор уровней, сборка сайта и рендер роликов |

## Включение (один раз)

1. **GitHub Pages:** Settings → Pages → Deploy from a branch → `main` и папка `/docs`.
2. **Аналитика:** в `docs/config.js` вписать `posthogKey` (ключ проекта PostHog, начинается с `phc_`) и, когда появится рекламный кабинет, `metaPixelId`. Туда же — ссылки на профили в `links`.
3. **Секреты репозитория** (Settings → Secrets and variables → Actions → New repository secret):
   - `BUFFER_API_KEY` — ключ API Buffer (publish.buffer.com/settings/api);
   - `POSTHOG_PERSONAL_API_KEY` — личный ключ PostHog с правом чтения запросов (Query read). Проект PostHog — 658447 (US), он уже прописан в workflow.
   Для облака PostHog в ЕС добавьте переменную `POSTHOG_API_HOST` = `https://eu.posthog.com` (вкладка Variables).
4. **Старт публикаций:** в `content/schedule.json` поставить `start_date` (например `"2026-10-18"`) и `site_url` (адрес демо со слешем на конце). Время выхода — `post_time_utc`, по умолчанию 22:30 UTC (18:30 в Нью-Йорке).

Проверить без публикации: Actions → Autopost clips → Run workflow. Скрипт напишет, что поставил в очередь или чего не хватает.

## Ссылки с метками

Органика размечается сама (`utm_source=instagram|threads|x|youtube`). Для рекламы используйте:

```
https://caypoh23.github.io/pixel-sort/?utm_source=meta&utm_medium=paid&utm_campaign=test1&utm_content=AD1
```

`utm_content` — номер ролика (AD1, AD2, AD3). По нему отчёт делит игроков по креативам.

"""Queue the day's Pixel Sort clip on every connected Buffer channel.

Runs from GitHub Actions. Reads content/schedule.json, remembers what it queued in
content/posted.json, and schedules each post for its exact time with Buffer's GraphQL API.

  python3 scripts/autopost.py               # queue posts due in the next 30 hours
  python3 scripts/autopost.py --dry-run     # print the plan, call nothing
  python3 scripts/autopost.py --introspect  # print Buffer's post input types (needs the key)

Needs the BUFFER_API_KEY secret. Without it the script explains what is missing and exits 0.
"""
import datetime as dt
import json
import os
import sys
import urllib.error
import urllib.request

ROOT = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
SCHEDULE = os.path.join(ROOT, "content", "schedule.json")
STATE = os.path.join(ROOT, "content", "posted.json")
API = "https://api.buffer.com"
LOOKAHEAD_H = 30
SERVICE_KEYS = {"instagram": "instagram", "youtube": "youtube", "threads": "threads", "twitter": "x", "x": "x"}


def gql(key, query, variables=None):
    body = json.dumps({"query": query, "variables": variables or {}}).encode()
    req = urllib.request.Request(API, data=body, method="POST", headers={
        "Authorization": "Bearer " + key, "Content-Type": "application/json", "User-Agent": "pixel-sort-autopost"})
    try:
        with urllib.request.urlopen(req, timeout=60) as r:
            out = json.loads(r.read().decode())
    except urllib.error.HTTPError as e:
        raise SystemExit(f"Buffer API HTTP {e.code}: {e.read().decode()[:500]}")
    if out.get("errors"):
        raise RuntimeError(json.dumps(out["errors"])[:800])
    return out["data"]


TYPE_Q = """query($n: String!) { __type(name: $n) { name kind enumValues { name }
  inputFields { name type { kind name ofType { kind name ofType { kind name ofType { kind name } } } } } } }"""


def unwrap(t):
    required = False
    while t and t.get("kind") in ("NON_NULL", "LIST"):
        if t["kind"] == "NON_NULL":
            required = True
        t = t.get("ofType")
    return (t or {}).get("name"), (t or {}).get("kind"), required


class Schema:
    def __init__(self, key):
        self.key, self.cache = key, {}

    def t(self, name):
        if name not in self.cache:
            self.cache[name] = gql(self.key, TYPE_Q, {"n": name})["__type"] or {}
        return self.cache[name]

    def fields(self, name):
        return {f["name"]: unwrap(f["type"]) for f in (self.t(name).get("inputFields") or [])}

    def enum(self, name):
        return [v["name"] for v in (self.t(name).get("enumValues") or [])]


def pick_enum(values, *wanted):
    low = {v.lower(): v for v in values}
    for w in wanted:
        for lv, v in low.items():
            if lv == w or w in lv:
                return v
    return values[0] if values else None


def network_metadata(schema, meta_type, network, day):
    """Fill the per-network metadata input by inspecting its schema, so field drift does not break posting."""
    if network not in ("instagram", "youtube"):
        return None
    fields = schema.fields(meta_type)
    slot = next((f for f in fields if network in f.lower()), None)
    if not slot:
        return None
    tname, kind, _ = fields[slot]
    sub = schema.fields(tname)
    out = {}
    for fname, (ftype, fkind, req) in sub.items():
        lf = fname.lower()
        if network == "instagram":
            if lf == "type" and fkind == "ENUM":
                out[fname] = pick_enum(schema.enum(ftype), "reel")
            elif lf == "shouldsharetofeed":
                out[fname] = True
        if network == "youtube":
            if lf == "title":
                out[fname] = day["captions"]["youtube_title"][:100]
            elif "privacy" in lf and fkind == "ENUM":
                out[fname] = pick_enum(schema.enum(ftype), "public")
            elif "category" in lf:
                out[fname] = pick_enum(schema.enum(ftype), "gaming", "20") if fkind == "ENUM" else "20"
            elif "madeforkids" in lf:
                out[fname] = False
            elif "notify" in lf:
                out[fname] = True
            elif "license" in lf and fkind == "ENUM":
                out[fname] = pick_enum(schema.enum(ftype), "youtube", "standard")
            elif "embeddable" in lf:
                out[fname] = True
        if req and fname not in out:
            if fkind == "ENUM":
                out[fname] = schema.enum(ftype)[0]
            elif ftype == "Boolean":
                out[fname] = False
            else:
                print(f"  ! {network}.{fname} is required and unknown to this script", file=sys.stderr)
    return {slot: out} if out else None


def channels(key):
    orgs = gql(key, "{ account { organizations { id name } } }")["account"]["organizations"]
    found = {}
    for org in orgs:
        q = "query($i: ChannelsInput!) { channels(input: $i) { id name service isDisconnected } }"
        for ch in gql(key, q, {"i": {"organizationId": org["id"]}})["channels"]:
            net = SERVICE_KEYS.get(str(ch.get("service", "")).lower())
            if net and not ch.get("isDisconnected") and net not in found:
                found[net] = ch
    return found


def due_posts(schedule, now):
    if not schedule.get("start_date"):
        return []
    start = dt.date.fromisoformat(schedule["start_date"])
    hh, mm = map(int, schedule.get("post_time_utc", "22:30").split(":"))
    out = []
    for day in schedule["days"]:
        if not day.get("file"):
            continue
        when = dt.datetime.combine(start + dt.timedelta(days=day["day"] - 1), dt.time(hh, mm), tzinfo=dt.timezone.utc)
        if now + dt.timedelta(minutes=10) <= when <= now + dt.timedelta(hours=LOOKAHEAD_H):
            out.append((when, day))
    return out


def text_for(day, net, schedule):
    link = schedule["site_url"] + f"?utm_source={net}&utm_medium=organic&utm_campaign=launch&utm_content={day['clip']}"
    caps = day["captions"]
    if net == "youtube":
        return caps["youtube"]
    return caps[net].replace("{LINK}", link)


def main():
    args = set(sys.argv[1:])
    schedule = json.load(open(SCHEDULE))
    state = json.load(open(STATE)) if os.path.exists(STATE) else {}
    now = dt.datetime.now(dt.timezone.utc)
    plan = due_posts(schedule, now)
    key = os.environ.get("BUFFER_API_KEY", "").strip()

    if "--introspect" in args:
        if not key:
            raise SystemExit("BUFFER_API_KEY is not set")
        s = Schema(key)
        print(json.dumps({"CreatePostInput": s.fields("CreatePostInput")}, indent=1))
        meta = s.fields("CreatePostInput").get("metadata", (None,))[0]
        if meta:
            print(json.dumps({meta: s.fields(meta)}, indent=1))
            for f, (tn, _, _) in s.fields(meta).items():
                print(json.dumps({tn: s.fields(tn)}, indent=1))
        print(json.dumps({k: v["id"] for k, v in channels(key).items()}, indent=1))
        return

    if not schedule.get("start_date"):
        print("Posting is paused: set start_date in content/schedule.json to begin.")
        return
    if not plan:
        print("Nothing due in the next", LOOKAHEAD_H, "hours.")
        return
    if "--dry-run" in args or not key:
        if not key:
            print("BUFFER_API_KEY is not set, showing the plan only.")
        for when, day in plan:
            for net in schedule["channels"]:
                print(when.isoformat(), net, day["file"], "|", text_for(day, net, schedule)[:90])
        return

    s = Schema(key)
    input_fields = s.fields("CreatePostInput")
    meta_type = input_fields.get("metadata", (None,))[0]
    mode_field = "mode" if "mode" in input_fields else ("shareMode" if "shareMode" in input_fields else None)
    chans = channels(key)
    print("Connected channels:", ", ".join(sorted(chans)) or "none")
    mutation = """mutation($input: CreatePostInput!) { createPost(input: $input) {
      __typename ... on PostActionSuccess { post { id dueAt } } ... on MutationError { message } } }"""
    failures = 0
    for when, day in plan:
        for net in schedule["channels"]:
            tag = f"day{day['day']}:{net}"
            if tag in state:
                continue
            ch = chans.get(net)
            if not ch:
                print("skip", tag, "- channel not connected in Buffer")
                continue
            video_url = schedule["site_url"] + "clips/" + day["file"]
            inp = {"text": text_for(day, net, schedule), "channelId": ch["id"], "schedulingType": "automatic",
                   "dueAt": when.strftime("%Y-%m-%dT%H:%M:%S.000Z"),
                   "assets": [{"video": {"url": video_url, "metadata": {"thumbnailOffset": 300}}}]}
            if mode_field:
                inp[mode_field] = "customScheduled"
            if meta_type:
                md = network_metadata(s, meta_type, net, day)
                if md:
                    inp["metadata"] = md
            try:
                res = gql(key, mutation, {"input": inp})["createPost"]
            except RuntimeError as e:
                print("error", tag, e); failures += 1
                continue
            if res.get("__typename") == "PostActionSuccess":
                state[tag] = {"id": res["post"]["id"], "dueAt": res["post"]["dueAt"], "file": day["file"]}
                print("queued", tag, res["post"]["dueAt"])
            else:
                print("rejected", tag, res.get("message")); failures += 1
    json.dump(state, open(STATE, "w"), indent=1, sort_keys=True)
    if failures and not state:
        raise SystemExit(f"{failures} posts failed and none were queued")


if __name__ == "__main__":
    main()

"""Daily Pixel Sort test report from PostHog.

Pulls the play funnel by traffic source and by ad creative, writes reports/latest.md,
reports/<date>.md and docs/data/report.json. Runs from GitHub Actions every morning.

Needs secrets POSTHOG_PERSONAL_API_KEY (scope: query read) and POSTHOG_PROJECT_ID.
Optional POSTHOG_API_HOST (default https://us.posthog.com; EU cloud: https://eu.posthog.com).
Without them the script explains what is missing and exits 0.
"""
import datetime as dt
import json
import os
import urllib.error
import urllib.request

ROOT = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))

# Working targets for a browser prototype; revisit after the first 300 players.
TARGETS = {"play_rate": 0.70, "l1_rate": 0.60, "l3_rate": 0.30, "yes_rate": 0.40}

NOT_DEMO = "toString(properties.watched_solution) != 'true'"
FUNNEL = f"""
SELECT {{group}} AS grp,
  uniqIf(distinct_id, event = 'level_start') AS visitors,
  uniqIf(distinct_id, event = 'first_move') AS played,
  uniqIf(distinct_id, event = 'level_complete' AND {NOT_DEMO} AND toFloat(properties.level) >= 1) AS done_l1,
  uniqIf(distinct_id, event = 'level_complete' AND {NOT_DEMO} AND toFloat(properties.level) >= 3) AS done_l3,
  uniqIf(distinct_id, event = 'install_intent') AS answered,
  uniqIf(distinct_id, event = 'install_intent' AND toString(properties.answer) = 'yes') AS said_yes,
  uniqIf(distinct_id, event = 'share_click') AS shared
FROM events
WHERE timestamp > now() - INTERVAL {{days}} DAY {{where}}
GROUP BY grp ORDER BY visitors DESC LIMIT 40
"""
SOURCE = "coalesce(nullIf(toString(properties.utm_source), ''), 'direct')"
CREATIVE = "coalesce(nullIf(toString(properties.utm_content), ''), '(none)')"
ADS_WHERE = "AND toString(properties.utm_medium) IN ('paid', 'cpc', 'ads')"
LEVELS = f"""
SELECT toInt(toFloat(properties.level)) AS level, count() AS completions,
  round(avg(toFloat(properties.seconds)), 1) AS avg_seconds,
  round(avg(toFloat(properties.moves)), 1) AS avg_moves,
  round(avg(toFloat(properties.undos)), 2) AS avg_undos,
  round(avg(if(toString(properties.booster) = 'true', 1, 0)), 2) AS booster_share
FROM events
WHERE event = 'level_complete' AND {NOT_DEMO} AND timestamp > now() - INTERVAL 7 DAY
GROUP BY level ORDER BY level
"""
DAILY = """
SELECT toDate(timestamp) AS day,
  uniqIf(distinct_id, event = 'level_start') AS visitors,
  uniqIf(distinct_id, event = 'first_move') AS played,
  uniqIf(distinct_id, event = 'level_complete' AND toFloat(properties.level) >= 1) AS done_l1
FROM events WHERE timestamp > now() - INTERVAL 14 DAY
GROUP BY day ORDER BY day
"""


def query(host, project, key, sql):
    body = json.dumps({"query": {"kind": "HogQLQuery", "query": sql}}).encode()
    req = urllib.request.Request(f"{host}/api/projects/{project}/query/", data=body, method="POST",
                                 headers={"Authorization": "Bearer " + key, "Content-Type": "application/json"})
    try:
        with urllib.request.urlopen(req, timeout=120) as r:
            out = json.loads(r.read().decode())
    except urllib.error.HTTPError as e:
        raise SystemExit(f"PostHog HTTP {e.code}: {e.read().decode()[:600]}")
    cols = out.get("columns") or []
    return [dict(zip(cols, row)) for row in out.get("results") or []]


def rate(a, b):
    return (a / b) if b else None


def pct(x):
    return "–" if x is None else f"{x * 100:.0f}%"


def flag(x, target):
    if x is None:
        return ""
    return " ✅" if x >= target else " ⚠️"


def funnel_table(rows, label):
    head = f"| {label} | Visitors | Played | Finished L1 | Finished L3 | Said yes | Shared |\n|---|---:|---:|---:|---:|---:|---:|\n"
    lines = []
    for r in rows:
        pr, l1, l3, yes = rate(r["played"], r["visitors"]), rate(r["done_l1"], r["played"]), rate(r["done_l3"], r["played"]), rate(r["said_yes"], r["answered"])
        lines.append(f"| {r['grp']} | {r['visitors']} | {r['played']} ({pct(pr)}) | {r['done_l1']} ({pct(l1)}) | "
                     f"{r['done_l3']} ({pct(l3)}) | {r['said_yes']}/{r['answered']} ({pct(yes)}) | {r['shared']} |")
    return head + ("\n".join(lines) if lines else "| no data yet | | | | | | |") + "\n"


def main():
    key = os.environ.get("POSTHOG_PERSONAL_API_KEY", "").strip()
    project = os.environ.get("POSTHOG_PROJECT_ID", "").strip()
    host = (os.environ.get("POSTHOG_API_HOST") or "https://us.posthog.com").rstrip("/")
    if not key or not project:
        print("Report skipped: add POSTHOG_PERSONAL_API_KEY and POSTHOG_PROJECT_ID as repository secrets.")
        return
    q = lambda sql: query(host, project, key, sql)
    by_source_7d = q(FUNNEL.format(group=SOURCE, days=7, where=""))
    by_source_1d = q(FUNNEL.format(group=SOURCE, days=1, where=""))
    by_creative = q(FUNNEL.format(group=CREATIVE, days=7, where=ADS_WHERE))
    levels = q(LEVELS)
    daily = q(DAILY)

    tot = {k: sum(r[k] for r in by_source_7d) for k in ("visitors", "played", "done_l1", "done_l3", "answered", "said_yes", "shared")}
    rates = {"play_rate": rate(tot["played"], tot["visitors"]), "l1_rate": rate(tot["done_l1"], tot["played"]),
             "l3_rate": rate(tot["done_l3"], tot["played"]), "yes_rate": rate(tot["said_yes"], tot["answered"])}
    today = dt.datetime.now(dt.timezone.utc).date().isoformat()
    md = [f"# Pixel Sort test report · {today}\n",
          "Last 7 days, unique browsers. Demo plays (Watch button) are excluded from level counts.\n",
          "## Summary\n",
          f"- Visitors: **{tot['visitors']}**, played at least one move: **{tot['played']}** ({pct(rates['play_rate'])}{flag(rates['play_rate'], TARGETS['play_rate'])}; target {pct(TARGETS['play_rate'])})",
          f"- Finished level 1: **{tot['done_l1']}** of players ({pct(rates['l1_rate'])}{flag(rates['l1_rate'], TARGETS['l1_rate'])}; target {pct(TARGETS['l1_rate'])})",
          f"- Finished level 3: **{tot['done_l3']}** of players ({pct(rates['l3_rate'])}{flag(rates['l3_rate'], TARGETS['l3_rate'])}; target {pct(TARGETS['l3_rate'])})",
          f"- Would install: **{tot['said_yes']} of {tot['answered']}** answers ({pct(rates['yes_rate'])}{flag(rates['yes_rate'], TARGETS['yes_rate'])}; target {pct(TARGETS['yes_rate'])})",
          f"- Shared the game: **{tot['shared']}**\n",
          "## By traffic source, 7 days\n", funnel_table(by_source_7d, "Source"),
          "## By traffic source, last 24 hours\n", funnel_table(by_source_1d, "Source"),
          "## Paid ads by creative, 7 days (utm_medium=paid)\n", funnel_table(by_creative, "Creative"),
          "## Levels, 7 days\n",
          "| Level | Completions | Avg seconds | Avg moves | Avg undos | Used +1 tube |\n|---:|---:|---:|---:|---:|---:|\n" +
          ("\n".join(f"| {r['level']} | {r['completions']} | {r['avg_seconds']} | {r['avg_moves']} | {r['avg_undos']} | {pct(r['booster_share'])} |" for r in levels) or "| – | | | | | |") + "\n",
          "## Daily, 14 days\n",
          "| Day | Visitors | Played | Finished L1 |\n|---|---:|---:|---:|\n" +
          ("\n".join(f"| {r['day']} | {r['visitors']} | {r['played']} | {r['done_l1']} |" for r in daily) or "| – | | | |") + "\n"]
    text = "\n".join(md)
    os.makedirs(os.path.join(ROOT, "reports"), exist_ok=True)
    open(os.path.join(ROOT, "reports", "latest.md"), "w").write(text)

              open(os.path.join(ROOT, "docs", "data", "report.json"), "w"), indent=1, default=str)
    print(text)

def setup(page, seg):
    ids = page.evaluate("PS.levels.map(L => L.id)")
    seg = dict(seg)
    if seg["type"] == "album":
        seg["slots"] = [ids.index(x) if x else -1 for x in seg["slots"]]
        seg["fresh"] = [ids.index(x) for x in seg["fresh"]]
        return page.evaluate("cfg => PS.video.album(cfg)", seg)
    seg["level"] = ids.index(seg.pop("pic"))
    return page.evaluate("cfg => PS.video.setup(cfg)", seg)


def get_audio(page, **opts):
    b64 = page.evaluate("o => PS.video.audio(o)", opts)
    a = np.frombuffer(base64.b64decode(b64), dtype=np.float32).reshape(-1, 2)
    assert np.isfinite(a).all()
    return a


def write_wav(path, a):
    a = np.clip(a, -1, 1)
    pcm = (a * 32767).astype("<i2")
    with wave.open(path, "wb") as w:
        w.setnchannels(2); w.setsampwidth(2); w.setframerate(RATE); w.writeframes(pcm.tobytes())


def loudnorm_args(wav):
    r = subprocess.run(["ffmpeg", "-hide_banner", "-i", wav, "-af", "loudnorm=I=-14:TP=-1.5:LRA=11:print_format=json", "-f", "null", "-"],
                       capture_output=True, text=True)
    m = json.loads(re.search(r"\{[\s\S]*?\}", r.stderr[r.stderr.rfind("[Parsed_loudnorm"):]).group(0))
    return ("loudnorm=I=-14:TP=-1.5:LRA=11:linear=true:"
            f"measured_I={m['input_i']}:measured_TP={m['input_tp']}:measured_LRA={m['input_lra']}:"
            f"measured_thresh={m['input_thresh']}:offset={m['target_offset']}"), m


def render_clip(page, cid):
    clip = CLIPS[cid]
    segs = clip["segments"]
    # pass 1: durations and sound effects
    infos, nframes, sfx = [], [], []
    for seg in segs:
        info = setup(page, seg)
        n = int(round(info["duration"] * FPS))
        infos.append(info); nframes.append(n)
        sfx.append(get_audio(page, music=False, duration=n / FPS))
    total_frames = sum(nframes)
    total = total_frames / FPS
    music = get_audio(page, sfx=False, duration=total)
    mixa = music.copy()
    off = 0
    for n, a in zip(nframes, sfx):
        s = int(round(off / FPS * RATE))
        mixa[s:s + len(a)] += a[: max(0, len(mixa) - s)]
        off += n
    peak = float(np.abs(mixa).max())
    if peak > 0.97:
        mixa *= 0.97 / peak
    wav = os.path.join(OUT, cid + "_audio.wav")
    write_wav(wav, mixa)
    af, meas = loudnorm_args(wav)
    # pass 2: frames piped into the encoder
    mp4 = os.path.join(OUT, clip["file"])
    enc = subprocess.Popen([
        "ffmpeg", "-y", "-hide_banner", "-loglevel", "error",
        "-f", "image2pipe", "-framerate", str(FPS), "-c:v", "png", "-i", "-",
        "-i", wav, "-map", "0:v", "-map", "1:a",
        "-c:v", "libx264", "-preset", "slow", "-crf", "18", "-pix_fmt", "yuv420p", "-profile:v", "high", "-level", "4.1",
        "-r", str(FPS), "-g", str(FPS * 2),
        "-af", af, "-c:a", "aac", "-b:a", "192k", "-ar", str(RATE),
        "-movflags", "+faststart", "-shortest", mp4], stdin=subprocess.PIPE)
    cover = None
    for seg, n in zip(segs, nframes):
        setup(page, seg)
        for f in range(n):
            d = page.evaluate("t => PS.video.frame(t)", f / FPS)
            png = base64.b64decode(d.split(",", 1)[1])
            if cover is None:
                cover = png
            enc.stdin.write(png)
    enc.stdin.close()
    if enc.wait() != 0:
        raise SystemExit("ffmpeg failed for " + cid)
    open(os.path.join(OUT, clip["file"].replace(".mp4", "_cover.png")), "wb").write(cover)
    return {"clip": cid, "file": mp4, "seconds": round(total, 2), "frames": total_frames,
            "moves": [i.get("moves") for i in infos], "input_lufs": meas["input_i"]}

"""Generate solvable Pixel Sort levels with an A* solver and export them as JSON.

Each level: the picture, the tube layout (bottom -> top, colour indexes) and an optimal
solution used by the "watch solve" demo and by the video renderer."""
import heapq, itertools, json, random, sys
from art import PICTURES, QMARK

CAP = 4


def is_goal(s):
    return all(len(t) == 0 or (len(t) == CAP and t.count(t[0]) == CAP) for t in s)


def h(s):
    cost = 0
    base = {}
    for t in s:
        if not t:
            continue
        run = 1
        while run < len(t) and t[run] == t[0]:
            run += 1
        cost += len(t) - run
        base.setdefault(t[0], []).append(run)
    for runs in base.values():
        if len(runs) > 1:
            runs.sort(reverse=True)
            cost += sum(runs[1:])
    return cost


def moves(s):
    first_empty_done = False
    for j, tj in enumerate(s):
        if len(tj) >= CAP:
            continue
        if not tj:
            if first_empty_done:
                continue
            first_empty_done = True
        for i, ti in enumerate(s):
            if i == j or not ti:
                continue
            if tj and tj[-1] != ti[-1]:
                continue
            if not tj and ti.count(ti[0]) == len(ti):
                continue  # moving a pure stack into an empty tube is pointless
            yield i, j


def apply(s, i, j):
    s = list(s)
    ti, tj = s[i], s[j]
    s[j] = tj + (ti[-1],)
    s[i] = ti[:-1]
    return tuple(s)


def solve(start, limit=400000):
    start = tuple(tuple(t) for t in start)
    key = lambda s: tuple(sorted(s))
    cnt = itertools.count()
    openq = [(h(start), 0, next(cnt), start)]
    parent = {key(start): (None, None)}
    gbest = {key(start): 0}
    states = {key(start): start}
    expanded = 0
    while openq:
        f, g, _, s = heapq.heappop(openq)
        k = key(s)
        if gbest.get(k, 1e9) < g:
            continue
        if is_goal(s):
            path = []
            while True:
                pk, mv = parent[key(s)]
                if pk is None:
                    break
                path.append(mv)
                s = pk
            return path[::-1], expanded
        expanded += 1
        if expanded > limit:
            return None, expanded
        for i, j in moves(s):
            n = apply(s, i, j)
            nk = key(n)
            ng = g + 1
            if ng < gbest.get(nk, 1e9):
                gbest[nk] = ng
                parent[nk] = (s, (i, j))
                heapq.heappush(openq, (ng + h(n), ng, next(cnt), n))
    return None, expanded


def check(start, path):
    s = [list(t) for t in start]
    for i, j in path:
        assert s[i], (i, j)
        assert len(s[j]) < CAP
        assert not s[j] or s[j][-1] == s[i][-1]
        s[j].append(s[i].pop())
    assert is_goal(tuple(tuple(t) for t in s))


def random_start(n, rng):
    balls = [c for c in range(n) for _ in range(CAP)]
    while True:
        rng.shuffle(balls)
        tubes = [balls[i * CAP:(i + 1) * CAP] for i in range(n)]
        if any(t.count(t[0]) == CAP for t in tubes):
            continue
        # no long runs: at most two equal neighbours in a tube
        bad = False
        for t in tubes:
            for a in range(CAP - 2):
                if t[a] == t[a + 1] == t[a + 2]:
                    bad = True
        if bad:
            continue
        return tubes + [[], []]


def completion_order(start, path):
    s = [list(t) for t in start]
    order = []
    for i, j in path:
        s[j].append(s[i].pop())
        t = s[j]
        if len(t) == CAP and t.count(t[0]) == CAP:
            order.append(t[0])
    return order


def build(pic_index, seed, want):
    pic = PICTURES[pic_index]
    keys = list(pic["palette"].keys())
    n = len(keys)
    rng = random.Random(seed)
    tried = 0
    while True:
        tried += 1
        start = random_start(n, rng)
        path, exp = solve(start)
        if path is None:
            continue
        if want(path, start):
            check(start, path)
            return start, path, tried


def pixel_orders(pic, seed):
    keys = list(pic["palette"].keys())
    rng = random.Random(seed)
    orders = []
    for ch in keys:
        idx = [y * 16 + x for y, r in enumerate(pic["rows"]) for x, c in enumerate(r) if c == ch]
        rng.shuffle(idx)
        orders.append(idx)
    return orders

   One time-based simulation drives both the playable page and the deterministic video renderer:

  const DATA = window.PS_DATA;
  const LEVELS = DATA.levels;
  const QMARK = DATA.qmark;

  const clamp = (x, a, b) => (x < a ? a : x > b ? b : x);
  const lerp = (a, b, t) => a + (b - a) * t;
  const easeOutCubic = (t) => 1 - Math.pow(1 - t, 3);
  const easeInOutCubic = (t) => (t < 0.5 ? 4 * t * t * t : 1 - Math.pow(-2 * t + 2, 3) / 2);

      t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
      return ((t ^ (t >>> 14)) >>> 0) / 4294967296;

  function tubeDone(i) { const t = G.tubes[i]; return t.length === CAP && t.every((b) => b.c === t[0].c); }
  function solved() { return G.tubes.every((t, i) => t.length === 0 || tubeDone(i)); }
  function anyMove() {
    for (let i = 0; i < G.nT; i++) { if (tubeDone(i)) continue; for (let j = 0; j < G.nT; j++) if (canMove(i, j)) return true; }
    return false;
  }

  function doSelect(i, t) {
    t = Math.max(t, G.busy[i]);
    const tube = G.tubes[i], b = tube[tube.length - 1];
    const a = ballPos(b, t);
    b.segs.push({ k: 'lift', t0: t, t1: t + 0.11, a, b: { x: a.x, y: G.lay.hoverY } });
    G.sel = i; G.selBall = b; G.selSince = t;
    G.selIntervals.push({ i, t0: t, t1: Infinity });
    sfx('lift', t, { k: tube.length - 1 });
    bump(t + 0.2);
    return t;
  }
  function closeSel(t) { const s = G.selIntervals[G.selIntervals.length - 1]; if (s && s.t1 === Infinity) s.t1 = t; }
  function doDeselect(t) {
    const i = G.sel, b = G.selBall; if (i < 0) return t;
    t = Math.max(t, G.selSince + 0.11);
    const k = G.tubes[i].length - 1;
    const a = ballPos(b, t), to = slotPos(i, k);
    b.segs.push({ k: 'drop', t0: t, t1: t + 0.12, a, b: to });
    b.lands.push(t + 0.12);
    G.busy[i] = Math.max(G.busy[i], t + 0.12);
    closeSel(t);
    G.sel = -1; G.selBall = null;
    sfx('settle', t + 0.12, { k });
    bump(t + 0.3);
    return t;
  }
  function doMove(j, t) {
    const i = G.sel, b = G.selBall;
    const dist = Math.abs(cx(j) - cx(i));
    const dTravel = 0.15 + dist * 0.00022;
    t = Math.max(t, G.selSince + 0.08, G.busy[j] - dTravel + 0.02);
    G.tubes[i].pop();
    const k = G.tubes[j].length;
    G.tubes[j].push(b);
    const a = ballPos(b, t), hov = { x: cx(j), y: G.lay.hoverY };
    b.segs.push({ k: 'travel', t0: t, t1: t + dTravel, a, b: hov, arc: 34 + dist * 0.06 });
    const to = slotPos(j, k);
    const dDrop = 0.08 + (to.y - hov.y) * 0.00022;
    const tl = t + dTravel + dDrop;
    b.segs.push({ k: 'drop', t0: t + dTravel, t1: tl, a: hov, b: to });
    b.lands.push(tl);
    G.busy[j] = tl; G.busy[i] = Math.max(G.busy[i], t);
    closeSel(t);
    G.sel = -1; G.selBall = null;
    G.history.push([i, j]);
    sfx('land', tl, { k });
    afterLand(j, tl);
    bump(tl + 0.3);
    return { t, tl };
  }

  function reveal(c, k, t) {
    if (k <= G.revealK[c]) return;
    const order = G.L.order[c], N = order.length;
    const from = Math.floor((N * G.revealK[c]) / CAP);
    const to = k >= CAP ? N : Math.floor((N * k) / CAP);
    G.revealK[c] = k;
    const n = to - from;
    if (n <= 0) return;
    const spread = Math.min(0.55, 0.012 * n + 0.08);
    for (let q = 0; q < n; q++) G.pixT[order[from + q]] = t + 0.04 + spread * (n === 1 ? 0 : q / (n - 1));
    sfx('reveal', t + 0.04, { n, spread });
    bump(t + spread + 0.5);
  }

  function afterLand(j, t) {
    const tube = G.tubes[j], c = tube[0].c;
    const pure = tube.every((b) => b.c === c);
    if (pure) reveal(c, tube.length, t);
    if (pure && tube.length === CAP) {
      G.complete[j] = t;
      G.bursts.push({ kind: 'pop', t, x: cx(j), y: G.lay.top - 6, col: G.L.colors[c], seed: 1000 + G.history.length * 37 + j });
      sfx('complete', t + 0.03, { c });
      bump(t + 1.2);
    }
    if (solved()) {
      G.winT = t + 0.25;
      G.bursts.push({ kind: 'confetti', t: G.winT + 0.45, seed: 4242 + G.idx });
      sfx('win', G.winT + 0.3, {});
      bump(G.winT + 4.5);
    }
  }

  function rebuild(history, extra, now) {
    const idx = G.idx;
    newGame(idx, { extra, extraT: extra ? G.extraT : -1e9 });
    G.silent = true;
    const T = -1000;
    for (const [i, j] of history) {
      const b = G.tubes[i].pop(), k = G.tubes[j].length;
      G.tubes[j].push(b);
      b.home = slotPos(j, k); b.segs = []; b.lands = [];
      G.history.push([i, j]);
      afterLand(j, T);
    }
    G.audio = []; G.silent = false;
    G.animEnd = now + 0.5;
  }

  function drawBall(b, p, t, sh) {
    const r = G.lay.r, spr = ballSprite(b.col, r);
    let sx = 1, sy = 1;
    for (let q = b.lands.length - 1; q >= 0; q--) {
      const lt = b.lands[q];
      if (lt <= t) { const u = (t - lt) / 0.2; if (u < 1) { const k = Math.sin(Math.PI * u) * (1 - u); sx = 1 + 0.14 * k; sy = 1 - 0.16 * k; } break; }
    }
    let x = p.x;
    if (sh) { const i = Math.round((p.x - G.lay.x0 - G.lay.tw / 2) / (G.lay.tw + G.lay.gap)); if (i >= 0 && i < sh.length && Math.abs(G.lay.cx(i) - p.x) < 2) x += sh[i]; }
    const S0 = spr.c.width, w = S0 * sx, h = S0 * sy;
    ctx.drawImage(spr.c, x - w / 2, p.y + r - (2 * r + spr.pad) * sy, w, h);
  }

  // ---------- sound (WebAudio synth, also used offline for videos) ----------
  const NOTE = (n) => 440 * Math.pow(2, (n - 69) / 12);
  const PENTA = [72, 74, 76, 79, 81, 84];
  function impulse(ac, dur, decay) {
    const len = Math.floor(ac.sampleRate * dur), buf = ac.createBuffer(2, len, ac.sampleRate), r = rng(1234);
    for (let ch = 0; ch < 2; ch++) { const d = buf.getChannelData(ch); for (let i = 0; i < len; i++) d[i] = (r() * 2 - 1) * Math.pow(1 - i / len, decay); }
    return buf;
  }
  function chain(ac, dest) {
    const input = ac.createGain();
    const comp = ac.createDynamicsCompressor();
    comp.threshold.value = -16; comp.ratio.value = 3; comp.attack.value = 0.004; comp.release.value = 0.25;
    const conv = ac.createConvolver(); conv.buffer = impulse(ac, 1.6, 3.2);
    const wet = ac.createGain(); wet.gain.value = 0.2;
    input.connect(comp); input.connect(conv); conv.connect(wet); wet.connect(comp); comp.connect(dest);
    return input;
  }
  function tone(ac, out, t, f, dur, o = {}) {
    const osc = ac.createOscillator(); osc.type = o.type || 'sine';
    osc.frequency.setValueAtTime(f, t);
    if (o.f2) osc.frequency.exponentialRampToValueAtTime(o.f2, t + (o.glide || 0.05));
    const g = ac.createGain(), gain = o.gain ?? 0.2, at = o.attack ?? 0.004;
    g.gain.setValueAtTime(0.0001, t); g.gain.exponentialRampToValueAtTime(gain, t + at); g.gain.exponentialRampToValueAtTime(0.0001, t + dur);
    osc.connect(g); g.connect(out); osc.start(t); osc.stop(t + dur + 0.05);
  }
  function noise(ac, out, t, dur, o = {}) {
    const len = Math.max(1, Math.floor(ac.sampleRate * dur)), buf = ac.createBuffer(1, len, ac.sampleRate), d = buf.getChannelData(0), r = rng(o.seed || 1);
    for (let i = 0; i < len; i++) d[i] = r() * 2 - 1;
    const s = ac.createBufferSource(); s.buffer = buf;
    const f = ac.createBiquadFilter(); f.type = o.type || 'bandpass'; f.frequency.value = o.freq || 2000; f.Q.value = o.q || 1;
    const g = ac.createGain(); g.gain.setValueAtTime(o.gain ?? 0.1, t); g.gain.exponentialRampToValueAtTime(0.0001, t + dur);
    s.connect(f); f.connect(g); g.connect(out); s.start(t); s.stop(t + dur + 0.02);
  }
  const VOICES = {
    lift(ac, out, t, p) { tone(ac, out, t, 560, 0.12, { gain: 0.13, f2: 880, glide: 0.07 }); tone(ac, out, t, 1120, 0.07, { gain: 0.025, f2: 1700, glide: 0.05 }); },
    settle(ac, out, t, p) { tone(ac, out, t, NOTE(PENTA[clamp(p.k, 0, 5)]) / 2, 0.12, { type: 'triangle', gain: 0.1 }); },
    land(ac, out, t, p) {
      const f = NOTE(PENTA[clamp(p.k, 0, 5)]);
      tone(ac, out, t, f, 0.26, { type: 'triangle', gain: 0.22 }); tone(ac, out, t, f * 2, 0.1, { gain: 0.05 });
      noise(ac, out, t, 0.025, { gain: 0.06, freq: 3400, q: 0.8, seed: 7 });
    },
    complete(ac, out, t) {
      [84, 88, 91, 96].forEach((n, i) => { const tt = t + i * 0.055; tone(ac, out, tt, NOTE(n), 0.9, { gain: 0.085 }); tone(ac, out, tt, NOTE(n) * 2.76, 0.3, { gain: 0.02 }); });
      noise(ac, out, t, 0.28, { gain: 0.009, freq: 7000, q: 0.7, type: 'highpass', seed: 11 });
    },
    reveal(ac, out, t, p) {
      const r = rng(Math.floor(t * 1000) + p.n), k = Math.min(8, 2 + Math.floor(p.n / 5));
      for (let i = 0; i < k; i++) tone(ac, out, t + p.spread * (i / k), NOTE(PENTA[(r() * 6) | 0] + 24), 0.12, { gain: 0.022 });
    },
    invalid(ac, out, t) { tone(ac, out, t, 210, 0.16, { type: 'square', gain: 0.04, f2: 140, glide: 0.12 }); },
    win(ac, out, t) {
      [72, 76, 79, 84].forEach((n, i) => tone(ac, out, t + i * 0.1, NOTE(n), 0.55, { type: 'triangle', gain: 0.13 }));
      [60, 64, 67, 72].forEach((n) => tone(ac, out, t + 0.42, NOTE(n), 1.8, { type: 'triangle', gain: 0.05, attack: 0.02 }));
      [96, 100, 103, 108].forEach((n, i) => tone(ac, out, t + 0.5 + i * 0.07, NOTE(n), 0.9, { gain: 0.025 }));
    },
    booster(ac, out, t) { [67, 72, 76].forEach((n, i) => tone(ac, out, t + i * 0.06, NOTE(n), 0.3, { type: 'triangle', gain: 0.09 })); },
  };
  function music(ac, out, t0, dur) {
    const beat = 60 / 96, bar = beat * 4;
    const prog4 = [[60, 64, 67, 72], [55, 59, 62, 67], [57, 60, 64, 69], [53, 57, 60, 65]];
    const bass = [48, 43, 45, 41];
    const g = ac.createGain();
    g.gain.setValueAtTime(0.0001, t0); g.gain.exponentialRampToValueAtTime(1, t0 + 0.03);
    g.gain.setValueAtTime(1, Math.max(t0 + 0.4, t0 + dur - 0.9)); g.gain.exponentialRampToValueAtTime(0.0001, t0 + dur);
    g.connect(out);
    const lp = ac.createBiquadFilter(); lp.type = 'lowpass'; lp.frequency.value = 2600; lp.connect(g);
    const pat = [0, 1, 2, 3, 2, 1, 2, 3];
    for (let b = 0; b * bar < dur; b++) {
      const ch = prog4[b % 4], tb = t0 + b * bar;
      for (let s = 0; s < 8; s++) { const t = tb + (s * beat) / 2; if (t > t0 + dur) break; tone(ac, lp, t, NOTE(ch[pat[s]] + 12), 0.34, { type: 'triangle', gain: s % 2 ? 0.036 : 0.046 }); }
      tone(ac, lp, tb, NOTE(bass[b % 4]), bar * 0.48, { type: 'triangle', gain: 0.09, attack: 0.01 });
      tone(ac, lp, tb + bar / 2, NOTE(bass[b % 4]), bar * 0.45, { type: 'triangle', gain: 0.072, attack: 0.01 });
      for (let q = 0; q < 4; q++) noise(ac, g, tb + q * beat + beat / 2, 0.04, { gain: 0.012, freq: 8000, type: 'highpass', seed: 3 + q + b * 4 });
    }
  }

  const Sound = {
    ac: null, out: null, bus: null, on: true, live: null,
    ensure() {
      if (this.ac) { if (this.ac.state === 'suspended') this.ac.resume(); return; }
      const AC = window.AudioContext || window.webkitAudioContext;
      if (!AC) return;
      this.ac = new AC();
      this.out = this.ac.createGain(); this.out.gain.value = 0.9; this.out.connect(this.ac.destination);
      this.newBus();
    },
    newBus() {
      if (!this.ac) return;
      if (this.bus) { try { this.bus.disconnect(); } catch (e) { /* already gone */ } }
      this.bus = chain(this.ac, this.out);
    },
  };

  function liveSfx(type, t, p) {
    if (!Sound.on || !Sound.ac || !Sound.bus || S.mode !== 'play') return;

    const at = Sound.ac.currentTime + Math.max(0, dt) + 0.01;
    VOICES[type] && VOICES[type](Sound.ac, Sound.bus, at, p);
  }

  function hitTube(x, y) {
    const lay = G.lay;
    if (y < lay.hoverY - lay.r - 60 || y > lay.bottom + 60) return -1;
    for (let i = 0; i < lay.n; i++) if (Math.abs(x - cx(i)) <= (lay.tw + lay.gap) / 2) return i;
    return -1;
  }

  function tapTube(i) {
    if (play.demo || G.winT < Infinity) return;
    const t = now();
    if (G.sel < 0) {
      if (!G.tubes[i].length || tubeDone(i)) { if (G.tubes[i].length) shake(i, t); return; }
      doSelect(i, t);
    } else if (G.sel === i) {
      doDeselect(t);
    } else if (canMove(G.sel, i)) {
      doMove(i, t);
      if (!play.moved) { play.moved = true; emit('first_move', { seconds: Math.round((t - play.levelT0) * 10) / 10 }); }
      if (G.winT === Infinity && !anyMove()) setTimeout(() => { emit('stuck', { moves: G.history.length }); notify('stuck'); }, 700);
    } else if (G.tubes[i].length && !tubeDone(i)) {
      doDeselect(t); doSelect(i, t + 0.02);
    } else {
      shake(i, t); doDeselect(t);
    }
    kick(); notify();
  }
  function shake(i, t) { G.shakes.push({ i, t }); sfx('invalid', t, {}); bump(t + 0.4); }

  function undo() {
    if (play.demo || !G.history.length || G.winT < Infinity) return;
    const t = now();
    const [i, j] = G.history[G.history.length - 1];
    const b = G.tubes[j][G.tubes[j].length - 1];
    const p = ballPos(b, t);
    const bid = b.id;
    rebuild(G.history.slice(0, -1), G.extra, t);
    play.undos++;
    emit('undo', { moves: G.history.length });
    const nb = G.balls[bid];
    nb.segs.push({ k: 'travel', t0: t, t1: t + 0.26, a: p, b: nb.home, arc: 50 });
    nb.lands.push(t + 0.26);
    sfx('settle', t + 0.26, { k: G.tubes[i].length - 1 });
    G.animEnd = t + 0.6;
    kick(); notify();
  }
  function addTube() {
    if (play.demo || G.extra || G.winT < Infinity) return false;

    rebuild(G.history, true, t);
    G.extraT = t;
    sfx('booster', t, {});
    emit('booster_used', { moves: G.history.length });
    G.animEnd = t + 0.7;
    kick(); notify();

  }
  function demo() {

  function scheduleSolution(t, cfg) {
    const r = rng(cfg.seed || 1), sol = G.L.solution;
    sol.forEach(([i, j], m) => {
      const pr = m / Math.max(1, sol.length - 1);
      const period = lerp(cfg.p0, cfg.p1, pr) * (0.92 + r() * 0.16);
      const hold = 0.2 + r() * 0.06;
      const ts = doSelect(i, t);
      G.taps.push({ x: cx(i), y: G.lay.top + G.lay.th * 0.55, t: ts });
      const mv = doMove(j, ts + hold);
      G.taps.push({ x: cx(j), y: G.lay.top + G.lay.th * 0.55, t: mv.t });
      t = ts + period;
    });
  }

  function frame() {
    play.raf = 0;
    const t = now();
    render(t, null);
    if (play.demo && G.winT < Infinity && t > G.winT) { play.demo = false; notify(); }
    if (t < G.animEnd || G.sel >= 0 || (G.winT < Infinity && t < G.winT + 4.5)) kick();
    if (G.winT < Infinity && t > G.winT + 1.2 && !play.winShown) {
      play.winShown = true;
      emit('level_complete', { moves: G.history.length, seconds: Math.round((G.winT - play.levelT0) * 10) / 10, undos: play.undos, booster: G.extra, watched_solution: !!G.byDemo });
      notify('win');
    }
  }
  function kick() { if (!play.raf && S.mode === 'play') play.raf = requestAnimationFrame(frame); }
  function notify(evt) { if (play.onState) play.onState(evt || 'update'); }
